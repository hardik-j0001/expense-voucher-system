# Expense Voucher Management System - Frontend

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm start
```

## Features

- React with Hooks
- Tailwind CSS for styling
- Role-based routing
- JWT authentication
- Dashboard with charts
- Voucher CRUD operations
- File upload for signatures
